# Data Video Transcription POCs

This repository contains separate proof-of-concept projects:

| Project | Description |
|---------|-------------|
| [POC_1_VIDEO_TRANSCRIPTION](POC_1_VIDEO_TRANSCRIPTION/README.md) | Local video-to-audio extraction and transcription using ffmpeg and faster-whisper. |
| [POC_2_TRANSCRIPTION_SEARCH](POC_2_TRANSCRIPTION_SEARCH/README.md) | Workspace for the upcoming transcription search POC. |

Each POC has its own README. POC 1's code, package configuration, and local data
are under `POC_1_VIDEO_TRANSCRIPTION/`. Follow its README for setup and execution.
